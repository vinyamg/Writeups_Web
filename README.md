# Portfólio de Segurança Web

 Este repositório apresenta estudos e cases de análise de segurança em aplicações web. 
O foco está em **metodologia, raciocínio e recomendações**, mantendo todos os exemplos **anonimizados e seguros**.

Todos os cases descrevem falhas observadas, processos de análise e aprendizados, sem exposição de dados sensíveis ou exploração de sistemas de terceiros
